# Criterios iniciales del modelo multicriterio

Pesos iniciales de prototipo:
- Adaptación climática: 25 %
- Compatibilidad con suelo: 25 %
- Salud del suelo: 20 %
- Viabilidad productiva: 20 %
- Prioridades del agricultor: 10 %

Estos pesos son una hipótesis de diseño que debe revisarse con el equipo y actores locales.

## Reglas
1. Aplicar restricciones críticas antes del ranking: falta severa de agua, incompatibilidad
   documentada de suelo, riesgo fitosanitario no manejable o calendario incompatible.
2. No puntuar un criterio si no hay datos suficientes; marcarlo como no evaluable.
3. No interpretar ausencia de datos como una condición favorable.
4. Penalizar repetición de familia botánica solo si la regla agronómica es pertinente
   para el cultivo, patógeno y contexto concretos.
5. Considerar cultivos de cobertura, residuos, leguminosas y diversidad de raíces
   como atributos potenciales, no como garantía automática de mejora del suelo.
6. Presentar puntuación, criterios, restricciones, fuentes e incertidumbre.

## Interpretación
El puntaje es una herramienta comparativa de apoyo, no una probabilidad de éxito,
un rendimiento esperado ni una recomendación automática de siembra.
